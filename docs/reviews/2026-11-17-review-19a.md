# Review 19a: OpenAI and xAI providers, the model catalog (2026-11-17)

**Package:** [19a](../implementation/19-agent-modes.md#19a--providers-and-the-model-catalog),
branch `impl/19a-providers`. Built by the lead directly (no junior package), like #67 and #68:
it reshapes the LLM adapter boundary that ADR-001 P1 guards, so it is lead work.

**Asked for by the owner:** three agent modes with models picked per role from any provider, with
"grok and openai api keys" planned for. 19a is the provider groundwork; the modes are 19b.

| Check | Result |

  has called OpenAI or xAI. Unverified: xAI accepting `max_completion_tokens`; xAI's usage field
  names (from its documented example: `prompt_tokens_details.cached_tokens`, reasoning outside
  `completion_tokens`); JSON mode on the GPT-6 family. The first live run in 19b checks all three.
- **OpenAI cache writes (A5):** compare the first OpenAI bill with Gaia's `llm_usage` total.
- **Historical docs** (handoffs 07a, 07b, 10b, 12b-2/3, 18b-2, and docs 07, 08) still say
  `deepseek_client.py`. They record what was built then and are left as they are.
