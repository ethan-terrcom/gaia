# Review: 07b — LLM gateway (D2)

**Reviewer:** lead engineer (Claude) · **Implemented by:** DeepSeek junior (`deepseek-v4-pro`, sandboxed harness)
**Date:** 2026-11-14 · **Branch:** `impl/07b-llm-gateway`

## Verdict
**Approve after lead fixes.** The gateway's shape is right:
- an exact-match allowlist;
- header allowlisting with the key injected server-side;
- provider-shaped errors;
- admin and run tokens kept strictly apart;
- atomic run-cost updates;
- metadata-only logging.

The review found **one budget bypass, confirmed with a reproducing test** (G1), plus a second way
calls went uncharged (G2), the redaction-registry leak also found in 13 (G3), and smaller items.
All are fixed with tests. The acceptance criterion was verified live against DeepSeek, with no
provider key in the client's environment.

## Findings

| ID | Severity | Where | Finding | Status |
|---|---|---|---|---|
| G1 | **High** | `gateway._relay_response` | **Disconnecting mid-stream made the call free.** Starlette cancels the response body through an anyio cancel scope, and every `await` in the generator's `finally`, including `_record_usage`, was cancelled as well. Reproduced: a stream that sends `message_start` (1,000 input tokens), then a client `http.disconnect`, ends in `CancelledError: Cancelled via cancel scope` inside the recording session, and no row is written. An agent that is interrupted or times out mid-answer would spend money the budget never sees. | **Fixed:** cleanup runs under `anyio.CancelScope(shield=True)` and `move_on_after(10)`. Regression test `test_a_client_disconnect_mid_stream_still_records_usage`. |
| G2 | High | `gateway._record_usage` | A 2xx response with no parsable usage was recorded at **$0** (`price_tier="unmetered"`). DeepSeek sends usage only in the final chunk, so every interrupted DeepSeek stream was free. | **Fixed:** `metering.estimate_usage` charges request and response bytes ÷ 3, all at the full input rate (`price_tier="estimated"`). Tests updated. |
| G3 | Medium | `run_tokens.mint` | Each token was added to the redaction registry, which is never pruned and is scanned on every log line (same class as 13's E3). | **Fixed:** a `gaia_rt_[\w-]{20,}` redaction **pattern** masks every run token by shape, also across restarts; there is no per-token registration. |
| G4 | Low | `run_tokens.revoke`, `RunTokenRepo.revoke_by_id` | Revocation by id ignored the workspace (F5 class). | **Fixed:** `revoke(session, workspace_id, token_id)`. |
| G5 | Low | `repo.daily_llm_usage_cost_usd` | `Decimal(float)` from SQLite's `SUM` carried the float's binary expansion. | **Fixed:** `Decimal(str(total))`. |
| G6 | Medium | `prices.toml`, `PriceTable` | DeepSeek prices were unverified placeholders, and the model could express only one off-peak window. DeepSeek's real schedule is **peak 01–04 and 06–10 UTC on weekdays**, with everything else half price. | **Fixed:** I read the official pricing page on 2026-11-14 and added `peak_windows_utc` and `peak_weekdays_only`. v4-pro peak rates are $1.32 miss / $0.044 hit / $3.96 out per 1M tokens. Chinese holidays are priced at peak, a conservative over-count. **Closes the owner follow-up "verify DeepSeek prices".** |
| G7 | Medium (open) | `ensure_budget` | The check runs before forwarding, so concurrent in-flight calls can each pass and overshoot by up to one call each. | Open → **18a**, which should reserve budget up front. Documented in `docs/backend/gateway.md`. |
| G8 | Info | `Run.budget_usd` | Defaults to `0`, so a run created without a budget is refused on its first call (fail-closed). | Note for **12a**: `RunManager.start` must set `budget_usd = settings.run_budget_usd`. |

At merge time the budget event was moved onto 13's `EventBus` (`EventType.RUN_BUDGET_EXCEEDED`),
resolving the junior's `TODO(gaia-13)`.

## Live verification (lead)
The server ran on a scratch data dir, through a lead-only launcher that loads the DeepSeek key into
an **in-memory** `SecretStore` inside the server process. Your keychain was not touched.
`scripts/dev_run_token.py --provider deepseek` printed a `gaia_rt_…` token.
- The client ran under `env -i`, with only `PATH`, `HOME`, the gateway URL and the run token
  (`provider-key-like env vars in client: []`). Gaia's own **`DeepSeekClient`**, with
  `base_url=…/llm/deepseek`, answered "Paris". 92 input and 19 output tokens, priced **off-peak**
  (Saturday), recorded on both sides.
- A **streaming** request through `curl` relayed 32 `data:` chunks and was metered (89 input, 30
  output tokens).
- `run.cost_usd` equals the sum of the two `llm_usage` rows.
- With the run's budget set to $0.000001, the next call got
  `{"error":{…,"type":"budget_exceeded","code":"budget_exceeded"}}`, **HTTP 403**.
- `grep -c` in the server log: run token **0**, real DeepSeek key **0**.

The Claude Agent SDK half of the criterion is part of the doc 08 spike, which runs through this
gateway next.
