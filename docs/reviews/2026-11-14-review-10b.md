## Lessons for the skills
- **"Register the current task" is a trap.** A runtime that cancels "its" task by holding
  `asyncio.current_task()` is holding its caller's. Run cancellable work in a child task, and
  decide on `current_task().cancelling()` whether the cancellation was yours. Added to the review
  skill.
- **Don't let a junior edit the contract to fit an implementation.** A per-runtime branch in a
  contract test is a review red flag in itself.
- **Every tool call needs an answer.** In OpenAI-compatible tool loops, any path that skips a
  `tool_call_id` (a break, an early return before results) yields a 400 on the next turn.
