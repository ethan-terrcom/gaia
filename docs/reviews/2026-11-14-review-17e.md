## Summary for the owner
The PRs page lists every pull request Gaia opened. For each it shows the ticket, the run's
status, CI and the review state, with a filter for open, merged and closed PRs that stays in the
URL. It updates live as CI and reviews change. It is the smallest view, and the junior got it
right first time: 40 turns, about $0.10.

## What I checked
- Loading, error (with retry) and empty states, all from the shared components.
- Ticket titles and repo names are rendered as plain text.
- The GitHub link is guarded (only `https://github.com/…`, new tab, `noreferrer noopener`).
- Query keys match the live-update map.
- The typed client: the request and response types come from the backend's generated schema, so
  a field mismatch fails `tsc`.
- Accessibility: `<table>` with `scope="col"` headers, and the filter buttons carry
  `aria-pressed`.
