## Checked
- Structlog switched to `stdlib.LoggerFactory` + `ProcessorFormatter.wrap_for_formatter`. Both
  handlers (console and file) use a formatter whose `foreign_pre_chain` redacts after
  `format_exc_info`.
- The E4 filter rewrites uvicorn's access `record.args` to drop the query; it is tested with a
  real `LogRecord` shape.
- `_SecureRotatingFileHandler` opens with `O_CREAT` mode `0o600` and re-`chmod`s after rotation.
- Repeated `configure_logging` calls neither duplicate handlers nor drop the file handler.
- `_serve` calls `configure_logging(log_dir=…)`, then `uvicorn.run(..., log_config=None)`, so
  uvicorn does not replace the handlers.
- The metrics SQL is in `gaia/db/repo.py`, workspace-scoped, with SQLite floats converted through
  `str` to `Decimal`; the empty database works.
