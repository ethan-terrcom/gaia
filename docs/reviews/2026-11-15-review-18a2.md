## Summary for the owner
The top bar now has a **Pause all** button, the emergency stop. It asks for confirmation and an
optional reason, then stops every running agent. A banner, "All runs are paused since … (reason)",
stays up with a **Resume all** button until you press it. While paused, starting a run tells you
why it can't.

In demo mode, an amber **Demo mode** badge reminds you that no real model is called. In the
approvals inbox, a **daily** budget pause now shows today's spend against the daily cap, and
explains that approving retries (after you raise the cap, or the next day) rather than granting
money.

## Findings
| # | Severity | Finding | Resolution |
|---|---|---|---|
| U1 | Low | The dashboard said "No step started yet" for a run whose steps had all **finished**. The API's `current_step` is null in both cases. | **Fixed:** "No step in progress". |

**Checked:**
- errors: the API client throws on any non-2xx response, so a 503 (orchestrator off) hides the
  control and a failed pause or resume shows inline;
- the pause is behind `ConfirmDialog`, and resume needs no dialog because it is safe;
- `run.status_changed` invalidates `['admin']`, so a pause made elsewhere appears;
- daily-scope decisions **omit** `budget_usd` entirely;
- reasons and messages render as plain text.
