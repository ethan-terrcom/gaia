## Summary for the owner
Anyone can now watch Gaia work **without API keys or spending money**:
- `gaia demo init` creates a small demo repository with one ticket;
- `GAIA_FAKE_LLM=1` replaces only the AI models with a scripted stand-in.

Everything else is the real system: the sandbox, the tests, git, the approvals, the cost
tracking and the UI. I ran it end to end in a real browser. From pressing Start run, through
approving the plan, to the "Open PR?" approval took a few seconds, with the change visible in the
diff and the (fake) spend on the dashboard. This is also what the user guide's first section uses.

## Findings
None blocking.

**Checked:**
- **No key, no network:**
  - the fake is an in-memory `httpx` transport that opens no sockets;
  - the gateway's demo seam uses a placeholder key and never calls the secret store (tested);
  - the server I ran had no provider key in its environment or store at all.
- **Fails safe:** the placeholder key and the fake transport hang off the same `settings.fake_llm`,
  so a real key can never be sent to the fake, nor the placeholder to a real provider. When the
  flag is off, the real-key path is byte-for-byte the old code.
- **The real `claude` CLI can't start:** both roles are forced onto the native runtime, with a
  warning, and asking for `claude_agent_sdk` returns 422.
- **Real wire formats:** the fake's answers are parsed by the real `AnthropicClient` (streamed SSE)
  and `DeepSeekClient` in tests, so the demo exercises the production parsers.
- `gaia demo init` is idempotent (run twice: "nothing duplicated"), and its repository's test
  command uses stdlib `unittest`, so it runs in the offline sandbox.
