## Summary for the owner
Tickets can now be created, edited, filtered and searched. The board groups them by status, and
a table view is one click away. "Start run" opens a dialog with an optional junior runtime and
budget, then takes you to the new run. If the ticket already has a run, or the orchestrator is
off, the dialog says so plainly.
